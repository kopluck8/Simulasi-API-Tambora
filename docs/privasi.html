Kebijakan Privasi – Simulasi API Tambora

Simulasi API Tambora adalah alat internal Balai Taman Nasional Gunung Tambora untuk pemodelan rambatan kebakaran hutan dan lahan. Aplikasi ini hanya dipakai oleh pemilik akun yang memberikan izin.

  • Akses Google Drive dipakai hanya untuk membaca data dasar spasial (GeoTIFF) dan menyimpan hasil landscape serta simulasi ke folder milik pengguna sendiri.
  • Tidak ada data pribadi yang dikumpulkan, dijual, atau dibagikan kepada pihak lain.
  • Kunci akses disimpan sebagai secret terenkripsi di GitHub Actions milik pengguna dan dapat dicabut kapan saja di myaccount.google.com/permissions.

Kontak: pemilik repositori github.com/kopluck8/Simulasi-API-Tambora.
