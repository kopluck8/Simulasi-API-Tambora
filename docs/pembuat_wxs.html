Pembuat file angin/cuaca .WXS

Mengunduh data cuaca per jam (reanalisis ERA5 / ECMWF IFS lewat Open-Meteo) lalu mengubahnya ke format Weather Stream (.wxs) FARSITE/FlamMap, satuan Metric. Bawaan: hotspot VIIRS Piong (savana, ±270 m dpl), tanggal hari ini, waktu WITA. Untuk simulasi di halaman ini, cuaca sudah dibuat otomatis di tab Simulasi. Koordinat 118,00 BT adalah puncak/kaldera (±1.300 m), jangan dipakai untuk savana.

Catatan pemakaian

  
    
    
  • Ini data model (reanalisis/analisis grid), bukan pengamatan stasiun. Satu sel grid 9–25 km meratakan pengaruh lereng, punggungan, dan kaldera, jadi angin lokal di Tambora bisa jauh berbeda. Untuk angin yang mengikuti topografi, jalankan WindNinja dengan kecepatan/arah dari file ini sebagai input domain-average.
    • 
    
  • Kolom: Year Mth Day Time Temp(°C) RH(%) HrlyPcp(mm) WindSpd(km/j pada 10 m) WindDir(° asal angin, searah jarum jam dari utara) CloudCov(%). Semua bilangan bulat kecuali curah hujan; RH dibatasi maksimal 99.
    • 
    
  • Ganti koordinat dengan titik api/hotspot yang Anda modelkan. RAWS_ELEVATION diisi elevasi titik yang dipakai Open-Meteo; suhu sudah dikoreksi ke elevasi itu.
    • 
    
  • Data ERA5 tersedia dengan jeda sekitar 5 hari; ECMWF IFS kadang punya jeda berbeda. Kalau satu model kosong, coba model lain dan bandingkan.
